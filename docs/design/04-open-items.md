# 미결과 남은 작업

> 2026-10-13 기준으로 정하지 않았거나 확인하지 못한 것입니다. 해결하면 이 문서에서 지우고 결과는 해당 설계 문서나 스펙에 적습니다.

## 미룬 작업

| 항목 | 미룬 이유 | 시작 조건 |
|---|---|---|
| 화면 편집 범위 넓히기(멤버, L3 이하, 그룹 추가·삭제, 모듈 ID 바꾸기) | [화면 편집 스펙](../superpowers/specs/2026-10-12-daemok-map-edit-design.md)이 모듈·그룹의 tier와 의존, 모듈 추가·삭제로 범위를 정했습니다 | L2 편집을 실제로 쓴 뒤 필요한 작업이 확인될 때 |
| 화면 편집 e2e를 CI에서 돌리기 | 브라우저와 node가 필요합니다. 지금은 `DAEMOK_E2E=1 go test ./internal/serve -run TestUIEditE2E`로 직접 돌립니다 | CI 실행기에 브라우저를 둘 수 있을 때 |
| VS Code 패널 | 지금은 브라우저 탭으로 씁니다. 패널은 같은 웹 페이지를 감싸는 방식으로 더하고, 웹뷰 안에서 루프백 검사가 그대로 동작하는지는 확인하지 않았습니다 | 브라우저와 에디터를 오가는 불편이 실제로 생길 때 |
| L0 외부 경계 생성 | 무엇을 생성할지 정하지 않았고 tolchain에 필요한 사례가 없습니다. 지금은 검사만 합니다 | 외부 경계 코드를 생성해야 하는 구체 사례가 생길 때 |
| MCP 쓰기 도구 | AI가 사용자 모르게 설계 파일을 고치지 못하게 도구를 모두 읽기 전용으로 두었습니다 | 쓰기 전에 사용자 확인을 받는 방식이 정해질 때 |
| 분석 병렬화 | 1000패키지 분석이 1.63초/회이고 96%가 파일 열기입니다. 실제 대상(25패키지)은 수십 ms입니다 | 큰 저장소에서 느리다는 사례가 나올 때 |
